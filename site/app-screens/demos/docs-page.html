Getting started / Quick start

Quick start

Install the client, create a key and send your first request. It takes about five minutes.

Install the client

The client works in Node 18 or later and in every modern browser. Pick your package manager.



Create an API key


Open Settings, then API keys, and choose New key. Keys start with nw_live_ or nw_test_. Store the key in an environment variable so it never lands in your code.


# .env
NORTHWIND_KEY=nw_test_4f9a…


ⓘ
Test keys are free. Requests made with a test key never touch live data and do not count towards your plan.


Send a request


Create a client with your key, then call projects.list(). Every method returns a promise.


import { Northwind } from '@northwind/client';

const nw = new Northwind({ key: process.env.NORTHWIND_KEY });

const projects = await nw.projects.list({ status: 'active', limit: 10 });
console.log(projects.data.map(p => p.name));


Parameters


All list methods accept the same options.


NameTypeWhat it does
statusstringOnly return items with this status: active, paused or archived.
limitnumberHow many items to return, from 1 to 100. The default is 25.
afterstringA cursor from the previous page, to fetch the next one.


Handle errors


Failed requests throw a NorthwindError with a status and a readable message. Rate-limited requests are retried for you up to three times.


try {
  await nw.projects.get('prj_missing');
} catch (err) {
  if (err.status === 404) console.log('No such project');
  else throw err;
}
