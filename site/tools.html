Tools

Everything you can make with the atlas. Each tool starts from the styles, kits and assets in the library, and hands its work to the next one: a brand into a site, a chart into a share image, a board into a theme kit.

How the tools connect

  • Brand kit generator → Site builder (colours, fonts and mark become a populated site), Moodboards (pin the kit) and My projects.
  • Theme kits → Site builder (“Use in the Site builder”), Moodboards (“Pin to moodboard”) and the Brand kit generator.
  • Moodboards → “Make this a style” builds a kit you can download, send to the Site builder or open in the Brand kit generator.
  • Chart, Diagram and Flowchart studios and the Site builder → Mockup studio (“Make share image”).
  • Icon library → Site builder (“Use as favicon”; every family is also in the builder’s Icons tab).
  • Site builder → My projects, a ZIP export, or Publish.
  • Flowchart studio ↔ Flowchart canvas: the same chart in the full or the lighter editor.
New to the atlas? Start with the UI interactions or browse the style catalogue.
