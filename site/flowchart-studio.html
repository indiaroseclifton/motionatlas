Steps Mermaid flowchart syntax

Syntax in one minute
a([Start])
start or end (pill)
b[Do a thing]
action
c{Approved?}
decision
d[(Database)]
data store
e[/Upload/]
input or output
f[[Sub-process]]
linked sub-process
[Title | note]
a second, quieter line
a --> b
connector
c -->|Yes| b
labelled branch
a -.-> b
optional or async
a ==> b
the main path
b:::have
status: have, dont, partial, accent
subgraph id [Stage]
group or lane, close with end

Or write one step per line. Lines ending in “?” become decisions, and indented Yes: step lines become branches.
