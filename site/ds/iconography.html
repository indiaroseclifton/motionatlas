Hard edges, every one.

One 24px set with a 1.5px stroke, square caps and mitred corners, so icons match the hard-edged type. Every icon is drawn from a single path, rendered by UI.icon(name), and inherits currentColor.

  • Icons 0
  • Grid 24px
  • Stroke 1.5px square

The set

Select an icon to copy its SVG. The grid is generated from the icon table inside 01-ui.js, so a new icon appears here the moment it ships.

Preview size

Construction

Draw on the 24px grid with a 2px safe area. Strokes only, no fills, no rounded joins. If an icon needs more than one idea, it is two icons.

  • Size 16px in dense rows and buttons, 20px in navigation, 24px stand-alone. Scale by the box; stroke stays 1.5.
  • Colour platinum 3 at rest, platinum on hover, cyan when current. Never green or amber unless the icon is the status.
  • Meaning icon-only buttons always carry an aria-label and a data-tip tooltip.

Usage

<button class="u-btn" type="button" data-icon="bolt">Deploy</button>
<button class="u-btn icon" type="button" data-icon="settings" aria-label="Settings" data-tip="Settings"></button>

el.innerHTML = UI.icon('agents');           // inline SVG string, aria-hidden
el.innerHTML = UI.icon('chart', 'my-class'); // with a class

Identity glyphs

Every agent, model and person gets a glyph: a mirrored 5×5 grid of bits, hashed from its name, so the same name always draws the same mark. Type a name to generate one.

The fleet

Do and don't

Do

  • Pair icons with a text label wherever space allows.
  • Use the glyph, not a stock avatar, for anything the system spawned.
  • Keep icons the same colour as their label.

Don't

  • Mix in icons from another set, or round their corners.
  • Fill icons, add duotone, or put them in coloured circles.
  • Use an icon alone for a destructive action.
