One press. One clear action.

A cyan trace draws across the top of every button on hover: the route the action will take. Platinum for the one primary action in a view, signal cyan for the hero action of a run, line for everything else.

  • Components 4
  • Class .u-btn
  • JS none required

Button

Five variants. Use exactly one solid or signal button per view; if two actions feel equally important, one of them is not.

Disabled link Link styled as button →

Anatomy

  1. Container36px tall, 1px line-2 border, 4px radius.
  2. Route trace::before, 1px cyan, draws 0→100% on hover with --e-route.
  3. IconOptional, 15px, before the label. Add with data-icon.
  4. LabelGeist 500 13.5px. A verb, sentence case.

Do

  • Start labels with a verb: Run, Deploy, Connect, Stop.
  • Use danger only for actions that stop or destroy, and confirm them in a dialog.
  • Use <a class="u-btn"> for navigation and <button> for actions.

Don't

  • Put two solid buttons side by side.
  • Use signal cyan for routine actions; it is the run's hero action.
  • Write "Click here", "Submit" or "OK".

Accessibility

  • Tab focuses, Enter and Space activate. Focus shows a 1.5px cyan ring via box-shadow.
  • Loading buttons keep their label in the DOM (it is only made transparent) and set aria-busy="true".
  • Prefer the native disabled attribute; on links use aria-disabled="true" and tabindex="-1".

Icon button

A square button with only an icon, for toolbars and row actions. It must always have an accessible name and a tooltip.

Do

  • Give every icon button an aria-label and matching data-tip.
  • Use ghost icon buttons inside rows and panels.

Don't

  • Use an icon-only button for a destructive action.
  • Use an icon whose meaning needs the tooltip to guess.

Button group

Related actions joined edge to edge, for switching views or stepping through records.

  • Wrap the group in role="group" with an aria-label.
  • If one option stays selected, use the segmented control instead.

Keyboard key

Shows a shortcut next to the action it triggers, in menus, tooltips and the command palette.

⌘ KCtrl Kesc↵/
