Anatomy

  1. HeaderMono 11px caps; sortable headers become buttons with an arrow.
  2. RowHeight --u-row, hairline below, hover tint.
  3. Primary celltd.t: platinum, often with a glyph.
  4. Numeric cell.r .u-num: right-aligned mono; sort uses data-v.

Do

  • Put the raw value in data-v so 88,310 sorts as a number.
  • Wrap the table in .u-table-wrap so it scrolls on its own on phones.

Don't

  • Zebra-stripe rows or draw vertical lines.
  • Centre numbers or mix units in one column.

Accessibility

  • Sort buttons set aria-sort="ascending|descending" on the header.
  • Give the scroll wrapper tabindex="0", role="region" and a label so keyboard users can scroll it.

Log

The machine's voice. Time in grey, action in cyan, value in green; amber for waits, red for faults. New lines flash once.

  • Wrap live streams in role="log" so new lines are announced politely.
  • Add class new to a fresh line for the one-time flash. Lines truncate with an ellipsis rather than wrap.
