Above the page, never in the way.

Dialogs for decisions, drawers for detail, menus for actions on one item, tooltips to name icon buttons, and the command palette for everything. All of them close with esc, and the dialogs are native <dialog> elements, so focus is trapped and restored for free.

Dialog

A modal decision. Title as a question, one sentence on the consequence, and two buttons named for what they do.

Stop this run?

48 agents will finish their current step and stand down. Work already done is kept.

Anatomy

  1. BackdropGraphite at 66% with a 3px blur.
  2. Header.hd: title (Geist 500 18px) and a close button.
  3. Body.bd: platinum 2, 14.5px.
  4. Footer.ft: actions, right-aligned, safe action first.

Accessibility

  • Opened with showModal(): focus moves inside, the page behind is inert, esc closes and focus returns to the trigger.
  • Label the dialog with aria-labelledby pointing at its title.

Do

  • Ask a question in the title and name both buttons with verbs.
  • Use a dialog only when the decision cannot be undone.

Don't

  • Write "Are you sure?" or use OK / Cancel.
  • Stack a dialog on a dialog.

Drawer

Menu

Actions on one item, opened from a button. Destructive items go last, after a divider, in soft red.

  • The trigger gets aria-haspopup="menu" and aria-expanded from UI.wire().
  • Opening focuses the first item; esc or a click outside closes and returns focus. Position is computed to stay inside the viewport.

Tooltip

A platinum label above an element on hover and keyboard focus, from a single attribute. Use it to name icon buttons, not to explain things.

  • data-tip is visual only: the accessible name must come from the label or aria-label.

Command palette

Everything, from anywhere, with ⌘ K. Type to filter, arrows to move, enter to run. On this site ⌘ K opens the docs search, so use the button to try the product palette.

  • The input is a combobox with aria-activedescendant pointing at the selected option in a listbox.
  • UI.palette.add(items) appends; keys adds hidden search words.
