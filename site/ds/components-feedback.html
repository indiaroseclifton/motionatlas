Toast

A short note in the bottom right that something happened. It plays its sound, stays 5.2 seconds and can be dismissed. The left edge carries the kind: cyan neutral, green success, amber warning, red error.

API

CallReturnsNotes
UI.toast(title, text?, kind?)The toast elementkind is '', 'ok', 'warn' or 'err'. Text is set with textContent, so it is safe for user data.

Accessibility

  • Toasts live in one role="status" aria-live="polite" region, created on first use.
  • Never put the only copy of an action in a toast: it disappears. Link to where the result lives.

Do

  • Lead with the outcome, then the proof: "Run complete · 6.2s".

Don't

  • Toast routine saves or every keystroke; quiet success is fine.

Banner

A full-width strip between hairlines for a condition that stays true until it is fixed. The tint fades from the left so it never becomes a box.

Skeleton

Shimmering bars in the shape of the content that is loading. Use for anything over 300ms; under that, show nothing.

  • The container is role="status" with aria-busy="true" and a label; remove both when the content lands.
  • The shimmer stops under reduced motion.

Inline progress
