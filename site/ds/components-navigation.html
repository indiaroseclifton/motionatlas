Tabs

Switch between views of one object. The selected tab underlines in cyan; counts sit beside labels in mono. Wrap in data-tabs and UI.wire() handles clicks and arrow keys.

Anatomy

  1. Tab list.u-tabs, hairline below, scrolls sideways when crowded.
  2. TabGeist 500 13.5px; platinum 3 at rest.
  3. Indicator1px cyan line on the selected tab.
  4. Count.n, mono 11px, optional.

Accessibility

  • ← → move and select; only the selected tab is in the tab order (roving tabindex).
  • Each tab has aria-controls; each panel has role="tabpanel" and aria-labelledby.
  • The wrapper fires a tab event with the index in detail.

Do

  • Use tabs for peer views of one thing.
  • Keep to five tabs or fewer.

Don't

  • Use tabs as page navigation; use links with aria-current.
  • Nest tabs inside tabs.
