Labels up. Errors that say what to do.

Every field has a visible label above it, a hint when it needs one, and an error underneath that tells people exactly how to fix it. Product UI uses these boxed fields; the showcase uses the underline o-input.

Field

The wrapper that stacks label, control, hint and error with a 6px gap. Every control below lives inside one.

Shown in logs and the swarm.

Set a budget above zero, or turn budgets off.

Anatomy

  1. Label.u-label, mono 11.5px caps, always visible.
  2. ControlInput, select, textarea or choice.
  3. Hint.u-help, optional, linked by aria-describedby.
  4. Error.u-error, replaces the hint while invalid.

Do

  • Validate when people press Continue, then focus the first problem.
  • Write errors as the fix: "Set a budget above zero".
  • Keep drafts on the device so nobody loses work.

Don't

  • Use placeholder text as the only label.
  • Validate on every keystroke or reset a form after an error.
  • Write "Invalid input" or "Required field".

Accessibility

  • Pair <label for> with every control's id.
  • Set aria-invalid="true" and point aria-describedby at the error so screen readers read it with the field.

Select and textarea

A native select with a drawn chevron, and a textarea that grows vertically. Native controls keep every platform's keyboard and screen reader behaviour for free.

Checkbox and radio

Square checkboxes and round radios that fill cyan when chosen. The whole label is the hit target.

Mode
  • Space toggles a checkbox; arrow keys move between radios in a group.
  • Group radios in a <fieldset> with a <legend>.

Switch

For settings that apply the instant they change, like sound or live updates. If the change waits for a Save button, use a checkbox.

  • A native checkbox with role="switch": screen readers announce on and off.
  • The thumb travels with --e-lock; under reduced motion it jumps.

Range

For continuous values. The filled part of the track is cyan, and the current value always shows as a number beside the label.

API

  • class="u-range" plus data-out="id" writes the value into that element on input; data-unit appends a unit. Wired by UI.wire().
  • Arrow keys step, Page Up/Page Down jump, Home/End go to the ends.

Segmented control

Two to four mutually exclusive views of the same data, like time ranges. It fires a change event with the chosen value.
