App templates.

22 finished screens for people building apps, dashboards, tools and pages: dashboards for sales, a CRM pipeline, stock and operations, a project timeline, landing, pricing, product and documentation pages, mobile banking and fitness apps, a calendar, kanban board, data table, file manager, inbox and AI chat, and the account screens every product needs. Every one is one HTML file with no libraries, works with a keyboard and folds down to a phone. Try any of them in six colours and four styles, light or dark, with the pickers below; what you choose is baked into the code you copy.

How to use these. Each file starts with its colour tokens: change --ac for your brand colour and the rest follows, in both themes. The sample data sits in plain arrays near the top of the script, ready to swap for a call to your own API. To restyle by hand, put data-skin="ocean" (or forest, sunset, rose, sand) and data-look="soft" (or sharp, serif, compact) on the html element, or add them to the address, for example #sand-serif-dark. The layouts follow familiar product patterns; the designs, names and code are our own.
